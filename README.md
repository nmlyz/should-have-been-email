should-have-been-email writes one line to a text file: a joke about a meeting that should have been an email. The line was picked from 36 candidates by pairwise judging against the brief — a remote meeting joined from different rooms in the same building, to say nothing to each other in high definition. It turns on its last word and names something true about meetings people have actually sat through, without ever saying the obvious line.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 105 characters, a single line, and ends on its strongest beat. The program builds the line from two clauses — the same building, then the high-definition silence — and checks the result against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
